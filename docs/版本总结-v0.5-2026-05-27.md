## 本次未提交更新总结

### 新增功能

- 桌面端新增右下角“请作者喝杯咖啡”悬浮入口，鼠标悬停或键盘聚焦时展示微信、支付宝收款码。
- 新增赞赏相关图片素材，并在 PyWebView 打包内嵌 HTML 时转为 data URI，保证单文件桌面包也能正常显示。

### 已有功能调整

- 登录按钮在已登录或显示“切换账号”状态下，会向后端传递 `forceReauth`，避免误走旧会话复用分支。
- CLI 登录命令保留 `forceReauth` 配置，并传给语雀登录流程，前端、桌面层、Node 层的切换账号语义保持一致。
- 强制切换账号时会清理旧 `cookies.json` 与独立浏览器资料目录，防止 Puppeteer 继续复用旧账号。
- 登录浏览器启动后会通过 CDP 清理语雀相关 Cookie、本地存储、缓存与 Service Worker，进一步降低旧账号自动恢复概率。
- 桌面窗口默认尺寸扩大到 1900 × 1040，最小尺寸提升到 1500 × 860，配合当前信息密度更高的导出配置界面。
- UI 圆角整体收敛，桌面端最小宽度固定为 1440px，并允许横向滚动，减少宽屏布局下的拥挤和折行。
- 知识库树根节点布局调整为宽度占满，文档数量靠右显示，长标题使用省略号，降低树形列表错位概率。

### 问题修复

- 修复“切换账号”可能直接复用当前账号、表现为点击后没有进入重新登录流程的问题。
- 修复强制切换账号时只删除 Cookie 文件但保留浏览器 userDataDir，导致旧语雀会话仍被恢复的问题。
- 修复新增赞赏图片在打包后的内嵌桌面页面中可能因本地资源路径不可用而无法显示的问题。

### 文档变更

- 新增本次版本总结文档，记录最近版本记录、本次未提交更新分类、提交范围和维护注意事项。
- 同步保留项目全景说明与软件界面截图资料，可作为后续 README 或发布页补充素材继续整理。

### 部署配置相关变更

- `.gitignore` 新增忽略 `.yuque-login-profile/` 与 `crash-reports/`，避免本地登录浏览器资料、Cookie 缓存和运行崩溃日志误入仓库。

## 维护注意事项

- 当前最重要的功能变更是“切换账号必须绕过旧会话复用”，后续测试应重点覆盖已登录后切换到另一个语雀账号的路径。

- `crash-reports/` 属于运行诊断输出，适合本地排查，不适合进入正式版本记录。
- 赞赏浮层属于桌面 UI 辅助入口，不影响导出内核；若后续做无赞赏版发行，可只移除前端浮层和三张赞赏素材映射。
