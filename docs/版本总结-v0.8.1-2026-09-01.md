# v0.8.1 版本总结：OTA 首包启动修复

- 版本：v0.8.1
- 日期：2026-09-01
- 发布主题：修复首个 OTA 更新包启动阻断并生成真实上传包
- 交付状态：本地代码、EXE、签名清单和自动化验收完成；宝塔上传与远端 HTTPS 闭环等待服务器操作。

## 一、为什么做

v0.8.0 的 OTA 主链路已经完成，但冻结 EXE 验收发现：旧版程序可能仍占用历史全局单实例锁名称，导致新版启动时被误判为重复实例。这个问题会直接阻断 OTA 安装后的新版健康检查，因此必须在首个真实 OTA 包发布前修复。

## 二、本次重要变化

### 问题修复

- 桌面端单实例锁改用 `Global\\YuqueExporterObsidianDesktopV2`，避开旧版残留锁，同时保留同版本禁止多开的行为。
- 启动前清空 Win32 上次错误码，单实例判断只依据当前 `CreateMutexW` 调用结果。

### 部署与发布

- 项目版本源更新为 `v0.8.1`。
- 重新构建 `release/YuqueExporterObsidian.exe`。
- 使用本机 Ed25519 私钥生成真实上传目录：`release/ota-upload/`。
- 发布包清单版本为 `0.8.1`，目标地址为：
  `https://update.baimoushare.cn/yuque2obsidian/releases/v0.8.1/YuqueExporterObsidian-0.8.1-win-x64.exe`
- EXE 大小：90,189,475 bytes。
- EXE SHA-256：`75fe0b58eb664d90e8c36e2cb9d8994c68ac2254de9d735150e5f329d6e83bc0`。

### 文档变更

- 新增本版本总结，并保留 v0.8.0 OTA 实施文档作为完整操作手册。

## 四、宝塔上传动作

将 `release/ota-upload/` 内文件上传到：

```text
C:/wwwroot/update.baimoushare.cn/yuque2obsidian
```

严格按 `release/ota-upload/上传顺序.txt`：

1. 上传 `releases/v0.8.1/YuqueExporterObsidian-0.8.1-win-x64.exe`。
2. 上传 `releases/v0.8.1/release-notes.md`。
3. 上传 `stable/manifest.sig`。
4. 最后上传 `stable/manifest.json`。

上传完成后，用手工安装的 v0.8.0 打开设置，执行“立即检查更新 → 下载更新 → 安装并重启”，再核对新版健康标记和回滚场景。
