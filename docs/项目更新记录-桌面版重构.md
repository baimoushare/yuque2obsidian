# 语雀→Obsidian 项目更新记录

> 记录日期：2026-03-22
> 适用范围：桌面版重构阶段至当前版本

## 1. 更新概览

本项目已经从早期的命令行导出脚本，重构为面向桌面端使用的完整导出工具，目标是稳定将语雀内容批量导出为 Markdown，并尽可能兼容导入 Obsidian 的使用场景。

本轮更新的重点包括：

- 重构为 `pywebview` 桌面壳 + Node.js 导出内核
- 提供可视化桌面界面，支持直接前端操作
- 支持图片、附件、表格、复杂块等内容导出
- 加强 Obsidian 路径兼容与资源目录管理
- 增加失败 CSV、增量导出、暂停继续、登录状态识别等能力
- 对 UI、交互和视觉样式进行了连续优化

---

## 2. 架构升级

### 2.1 桌面端架构重构

项目由单脚本方案升级为双层结构：

- 桌面壳：Python `pywebview`
- 导出内核：Node.js
- 前端界面：本地静态页面

当前职责划分如下：

- `desktop_app.py`
  - 启动桌面窗口
  - 启动本地静态服务
  - 暴露前端调用 API
  - 调起 Node 导出任务
  - 汇总任务状态与日志
- `desktop/ui/`
  - 提供桌面前端界面
  - 负责配置、知识库树、进度条、日志展示、交互控制
- `src/`
  - 承担语雀访问、导出计划构建、Markdown 处理、资源下载、失败记录、增量状态管理等工作

### 2.2 桌面 API 统一

前端当前通过 `pywebview` 统一调用以下能力：

- `loadSettings`
- `saveSettings`
- `chooseOutputDir`
- `startLogin`
- `scanBooks`
- `startExport`
- `getJobStatus`
- `cancelExport`
- `openOutputDir`
- `getLoginStatus`

这意味着后续新增功能时，可以继续沿用这套桥接设计，不需要反复改动基础通信方式。

## 3. 导出能力更新

### 3.1 批量导出知识库

当前版本支持：

- 扫描当前账号可访问的知识库
- 树形展示知识库与目录结构
- 多选知识库后统一导出
- 保留原有知识库目录层级

### 3.2 Markdown 导出流程重构

单篇文档导出流程已拆分为可追踪的阶段：

- 拉取 Markdown
- 改写链接与下载资源
- 提取表格与复杂块
- 写入本地 Markdown

这使得日志更清晰，也更方便在失败 CSV 中记录具体出错阶段。

### 3.3 图片与附件下载

在现有基础上补齐了资源下载链路，支持：

- 下载图片
- 下载附件
- 在 Markdown 中改写为本地相对路径

资源目录统一按知识库归档：

- `_assets/images`
- `_assets/files`
- `_assets/blocks`

### 3.4 表格、复杂块与快照补充

复杂内容采用“正文优先、复杂块补充”的策略：

- 普通 Markdown 正文优先保留
- HTML 表格尽量提取为可用内容
- 数据表、思维导图、画板等复杂块优先以快照或补充内容形式保存
- 复杂块提取失败时，尽量降级为警告，不直接让整篇 Markdown 失效

### 3.5 Obsidian 兼容处理

为了后续导入 Obsidian，已经做了这些适配：

- 所有资源改为相对路径
- 内部文档链接改写到本地 `.md`
- 统一使用知识库级资源目录
- 保留原始目录结构，方便 Obsidian Vault 中继续管理

## 4. 导出稳定性与容错更新

### 4.1 失败 CSV 记录

新增失败日志 CSV，特点包括：

- 使用时间戳命名
- 仅保留一份正式失败 CSV，不再默认生成两份
- 输出为 `UTF-8 with BOM`，兼容 Windows 下 Excel 打开中文
- 单篇失败时立即写入，不等待整批结束

CSV 当前重点记录：

- 时间
- 知识库名称
- 笔记名称
- 语雀路径
- 本地目标路径
- 失败阶段
- 错误类型
- 错误原因
- 重试次数

### 4.2 CSV 中文化

失败日志已改为中文描述，便于直接排查，例如：

- 失败阶段中文化
- 错误类型中文化
- 常见错误原因中文说明

### 4.3 单篇失败不再拖垮整批任务

当前逻辑已优化为：

- 某篇文档导出失败时
- 写入失败 CSV
- 在日志中标记
- 自动继续处理后续文档

不会再因为单篇异常直接导致整个任务立刻中断。

### 4.4 空文档自动识别

针对“只有标题、没有正文内容”的语雀文档，当前已做专门判定：

- 不生成 `.md`
- 不再产出误导性的失败占位内容
- 在 CSV 中记录为“空文档”
- 导出任务继续执行

### 4.5 复杂块失败降级

如果正文 Markdown 已经成功拿到，但复杂块提取失败：

- 优先保留已获得的正文
- 复杂块失败记录为警告
- 尽量避免整篇文档被错误覆盖成失败说明页

## 5. 增量导出、暂停与恢复

### 5.1 增量导出

新增导出状态文件与增量导出能力，支持：

- 跳过已经成功导出的文档
- 中断后再次运行时按状态续跑
- 避免每次都全量导出

### 5.2 暂停导出

当前暂停机制为协作式暂停：

- 点击暂停后，不会粗暴中断当前写文件动作
- 通常会在当前文档处理完成后暂停
- 暂停时保存当前导出状态

### 5.3 恢复导出

恢复方式为再次发起导出，系统将：

- 读取增量状态
- 跳过已完成内容
- 继续处理未完成部分

### 5.4 暂停后重新选择知识库

当前已增强“重新开始导出”时的选择逻辑：

- 不再只依赖旧的内存状态
- 会重新读取界面上当前真实勾选的知识库
- 再按最新选择发起导出

## 6. 加密文本块支持

### 6.1 多密码输入

导出配置中已经增加加密块密码支持，特点如下：

- 支持多组密码
- 一行一个密码
- 可长期保存到配置

### 6.2 小眼睛显示/隐藏密码

前端提供小眼睛按钮，支持：

- 查看当前填写的密码
- 切换显示/隐藏状态

### 6.3 导出时逐个尝试密码

遇到加密文本块时，系统会：

- 按顺序尝试所有预设密码
- 能解锁时尽量提取内容
- 全部失败时跳过该加密块并记录

### 6.4 解锁失败时的处理策略

当所有密码都不正确时：

- 不中断整篇文档导出
- 正文部分继续导出
- 失败信息写入 CSV
- 文档中尽量保留说明或快照痕迹

## 7. 登录状态与知识库扫描更新

### 7.1 登录状态识别

软件当前能够识别已登录账号，并在界面中展示：

- 已登录账号名称
- 登录用户名
- 未登录状态提示

### 7.2 登录按钮文案联动

按钮文案已更新为：

- 未登录时：`登录语雀`
- 已登录时：`切换账号`

### 7.3 启动后自动扫描知识库

如果启动软件时已经检测到有效登录状态，系统会：

- 自动扫描知识库
- 自动加载知识库树
- 将扫描结果写入任务日志区域

## 8. 进度与日志系统更新

### 8.1 双进度条展示

当前界面支持两层进度：

- 整体进度
- 当前知识库进度

并且补充了更明确的上下文信息：

- 整体进度旁显示当前正在导出的知识库
- 当前知识库进度旁显示当前正在导出的笔记

### 8.2 日志实时显示

任务日志区当前会统一显示：

- 启动提示
- 自动扫描提示
- 登录状态提示
- 导出阶段日志
- 警告信息
- 失败 CSV 路径提示

### 8.3 状态提示归并到日志区

此前零散的状态提示已逐步并入任务日志区，不再在界面上额外占用独立状态卡片。

## 9. 知识库选择交互更新

### 9.1 树形目录结构

知识库选择区已经升级为更接近语雀原生目录的树结构，支持：

- 无限层级嵌套
- 节点展开/折叠

当前界面支持显示：

- 文档总数量

- 普通点击

- `Shift` 区间选择

- 不再容易出现浏览器原生蓝色文本选区

### 9.4 选择控件样式统一

知识库勾选框已经改成统一的圆角矩形样式，并与导出配置中的勾选项保持一致。
