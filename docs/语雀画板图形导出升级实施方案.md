# 语雀画板图形导出升级实施方案

> 状态：执行中
> 目标：让语雀思维导图、简单流程图和复杂流程图按内容特征自动选择 Markdown/Markmap、Mermaid、Excalidraw 或 PNG，并保证可回退、可增量、安全不覆盖人工编辑。

## 1. 最终输出规则

```text
语雀画板 JSON
  → BoardIR（统一图形模型）
  → 分类器
    ├─ 纯思维导图 → Markmap；插件缺失时普通 Markdown
    ├─ 简单流程图 → Mermaid
    ├─ 布局敏感流程图 → Excalidraw；不可用时 PNG
    └─ 自由/不完整画板 → PNG + 原始 JSON + 告警
```

- 用户可见目录只保留一个主文件；原始 JSON、快照和清单统一放入 `_assets/boards`。
- 独立复杂流程图在 Excalidraw 成功后以 `.excalidraw.md` 为主文件，不生成同名 Markdown 外壳。
- 普通笔记中的复杂流程图保留原 Markdown，在原位置显示可稳定阅读的图像，并提供画板编辑入口。
- 再次导出前必须确认生成文件是否已被人工修改；人工修改过的文件禁止覆盖。

## 2. 分阶段实施

### V0.7：结构、分流和安全导出

1. 建立脱敏真实样本与当前行为基线。
2. 在 `src/board.js` 建立 BoardIR，保留节点坐标、尺寸、样式、锚点和连线信息。
3. 新增 `src/board-render.js`，负责分类、Markmap、Mermaid 和可见产物决策。
4. 修正 PNG 策略：`structured-first` 仅在结构化失败或部分成功时保留 PNG。
5. 新增输出清单、源哈希、生成哈希和人工修改保护。
6. 新增桌面端“图形导出模式”：自动推荐、通用兼容、Obsidian 可编辑增强。

### V0.8：Excalidraw 可编辑增强

1. 导出器把布局敏感流程图写入批处理任务目录。
2. 将 BoardIR 写成标准 Excalidraw `compressed-json` 文件；目标 Vault 已启用 Excalidraw 插件即可编辑，Obsidian CLI 仅用于可选的自动打开和命令调用，不作为生成硬前提。
3. 节点使用原生绑定文字，箭头使用双端绑定。对同一节点、同一连接方向的一对多/多对一连线，统一绑定到该方向对应的边中心。
4. 主轴使用直线；跨列分支优先保留语雀原始 `points/path` 路径；没有原始路径时才使用端点直线回退，不再按几何中点重新生成折线。不同方向分别使用各自边中心，禁止把向下连线强制接到右边或左边。
5. 读取生成结果，校验节点数、连线数、绑定数和错误信息。
6. 插件或 CLI 不可用时降级 PNG，不中断全书导出。

## 3. BoardIR 要求

节点：`id`、文字、形状、`x/y`、`width/height`、填充/边框/文字颜色、`zIndex`、原始顺序、思维导图子节点。

连线：`id`、起止节点、起止锚点、线形、箭头标记、颜色、原始点位、有效性。Excalidraw 导出优先保留原始点位；只有缺少原始路径时才使用端点直线回退，不再默认按几何中点生成折线。

图形：来源类型、结构完整度、布局完整度、不支持元素、告警、推荐输出格式。

## 4. 初始分类规则

- 纯思维导图：树结构完整，除辅助线外没有不支持元素。
- 简单流程图：不超过 20 节点、无无效连线、无图片/分组/自由绘制、最大汇入汇出不超过 3、主方向占比至少 70%。
- 布局敏感流程图：超过 20 节点、多列分布、汇入汇出复杂、直角线较多，或坐标布局明显影响阅读。
- 自由/不完整画板：结构完整度低于 70%，或主要是图片、分组、自由绘制。

阈值以真实样本回归结果为准，不在桌面端暴露为普通用户配置。

## 5. 文件策略

```text
正文目录/
  └─ 主文件（.md 或 .excalidraw.md）

_assets/boards/<文档>/
  ├─ board-*.yuque.json
  ├─ board-*.png（按策略）
  ├─ board-*.canvas（仅旧版兼容）
  ├─ board-*.manifest.json
  └─ _excalidraw-jobs/
```

- 不自动删除旧 Canvas、旧 PNG、旧 JSON 或旧 Excalidraw。
- 用户修改的 Excalidraw 发生源更新时，生成 `*.yuque-update.excalidraw.md` 供人工比较。
- 写入采用临时文件→校验→替换的原子流程；首版不自动清理历史版本。

## 6. 验收样本和门槛

样本至少包含：单根思维导图、带辅助线思维导图、三节点流程图、46 节点/49 连线复杂流程图、混合自由画板。

复杂流程图验收：

```text
节点 46 / 46
连线 49 / 49
绑定文字 46 / 46
起点绑定 49 / 49
终点绑定 49 / 49
```

运行时还必须验证：拖动节点时文字和连线跟随；重启 Obsidian 后绑定仍存在；原始折线路径中间折点未被导出器重算；同一方向的一对多/多对一连接点均为同一边中心；混合方向连线分别连接到正确边中心；插件缺失时导出降级但成功。

## 7. 代码边界

- `src/board.js`：解析、BoardIR、结构统计。
- `src/board-render.js`：分类、Markdown/Markmap/Mermaid/文件决策。
- `src/excalidraw.js`：任务创建、Obsidian 后处理、结果校验。
- `src/exporter.js`：导出编排、原子写入、文档内插入。
- `src/obsidian.js`：CLI/插件能力检测与显式配置。
- `desktop/ui/*`、`desktop_app.py`、`src/cli.js`：图形导出模式和状态展示。

## 8. 完成标准

1. 现有测试全部通过，新图形测试覆盖分类、回退、增量保护。
2. 真实样本批量导出无节点/连线丢失。
3. 思维导图和 Mermaid 在 Obsidian 中真实显示。
4. Excalidraw 样本完成节点、文字、箭头双端绑定与重启验证。
5. 用户手工修改的画板不会被增量导出覆盖。
6. 方案、验证记录和最终版本说明同步到本文件与 Clippings 副本。
