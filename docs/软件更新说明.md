# 语雀→Obsidian 软件更新说明

## 本次更新摘要

本次版本已将项目从早期脚本工具升级为桌面版导出工具，支持通过可视化界面完成语雀知识库扫描、批量导出、资源下载与任务跟踪。

## 主要更新内容

- 新增桌面端界面，支持直接在软件中完成登录、扫描、选择知识库和导出
- 导出架构重构为 `pywebview` 桌面壳 + Node.js 导出内核
- 支持图片、附件、表格及复杂块补充导出
- 新增 Obsidian 兼容处理，统一资源目录并改写相对路径
- 新增失败 CSV，使用中文记录失败笔记、路径、阶段和原因
- 新增强量导出、暂停后继续导出、导出状态保存
- 新增加密文本块多密码尝试与失败记录
- 新增登录状态识别、自动扫描知识库、知识库树形折叠选择
- 新增双进度条与实时任务日志显示
- 持续优化界面布局、滚动条、按钮、勾选框与整体毛玻璃视觉风格

## 当前版本价值

当前版本已经能够更稳定地将语雀内容整理为适合导入 Obsidian 的本地 Markdown 资料，同时保留知识库结构、资源附件和错误排查记录，便于长期使用与持续补导。
