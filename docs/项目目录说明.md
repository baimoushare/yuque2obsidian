# 项目目录说明

本文用于说明当前仓库中各目录和关键文件的职责，方便后续维护、封版和打包发布。

## 一、核心目录

### `desktop/`

桌面端界面资源目录。

- `desktop/ui/index.html`
桌面端页面结构。

- `desktop/ui/styles.css`
桌面端样式。

- `desktop/ui/app.js`
桌面端交互逻辑、配置读取、进度展示、失败重导入口等。

- `desktop/ui/assets/`
桌面端统一使用的图片与树形图标资源。

### `src/`

Node.js 导出内核目录，是项目主要业务逻辑所在。

主要模块分工如下：

- `exporter.js`
导出主流程、复杂内容处理、失败兜底、报告汇总。

- `yuque.js`
语雀接口访问、登录态校验、文档详情和表格数据抓取。

- `markdown.js`
Markdown 改写、链接与资源处理。

- `failure-log.js`
失败日志 CSV 输出与本地化描述。

- `obsidian.js`
Obsidian 仓库直写与导出布局规则。

- `board.js`
语雀画板与思维导图相关处理。

- `sheet.js`
语雀电子表格导出。

- `table.js`
语雀数据表结构化导出。

- `meld-encrypt.js`
加密块重加密相关能力。

- `cli.js`
命令行入口配置解析。

### `test/`

自动化测试目录。建议只保留正式测试文件，不再混入临时验证缓存。

### `docs/`

项目文档目录，建议后续持续只放下面几类资料：

- 方案设计
- 版本总结
- 问题修复记录
- 发布说明

## 二、运行与打包相关文件

### `desktop_app.py`

桌面程序入口，负责：

- 加载嵌入式前端页面
- 调度 Node.js 子进程
- 管理桌面配置、任务、日志与文件选择

### `desktop_retry.py`

根据失败日志 CSV 自动生成重导计划的辅助脚本。

### `build_windows_exe.ps1`

Windows 打包入口脚本，负责：

- 清理旧打包残留
- 生成图标
- 调用 PyInstaller
- 整理 `release/` 发布目录

### `YuqueExporterObsidian.spec`

PyInstaller 配置文件。

## 三、保留但默认不进版本库的目录

### `output/`

默认导出结果目录。  
属于运行产物，不建议提交到 Git。

### `release/`

桌面 EXE 打包结果目录。  
属于发布产物，不建议提交到 Git。

### `node_modules/`

Node.js 依赖目录。  
由 `npm install` 生成，不建议提交到 Git。

## 四、本地配置与临时产物约定

- `cookies.json`
本地登录态文件，通常保留在根目录供桌面端或打包产物使用。

- `desktop.settings.json`
本地桌面配置文件。

- `desktop-launch.log`
运行日志文件，应视为临时产物。

- `.tmp-*`、`.manual-packaging`、`.venv`
手工验证、打包中间过程或本地虚拟环境目录，应长期忽略。

## 五、当前整理后的维护建议

- 界面资源统一放在 `desktop/ui/assets/`，不要再往根目录放重复图片或 SVG
- 临时验证数据统一放到被忽略的临时目录，不要混入正式文档或源码目录
- 后续新增文档优先放入 `docs/`，并保持文件名语义清晰
- 如果准备正式封版，建议新增 `docs/发布说明-V0.3.md` 作为最终发布留档
