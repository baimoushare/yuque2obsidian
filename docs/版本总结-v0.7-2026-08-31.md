## 本次未提交版本定位

本轮更新的目标，是把语雀画板从“主要依赖截图或旧 Canvas 侧车”推进到“按结构和布局选择可维护产物”的导出链路：思维导图优先 Markmap/Markdown，简单流程图优先 Mermaid，复杂或布局敏感流程图优先生成可编辑 Excalidraw，自由或不完整画板保留 PNG 与原始 JSON。与此同时，增量导出必须保护用户手工修改，不能因再次同步覆盖已有成果。

交付边界已由实施方案、操作步骤、验证记录和自动化测试共同确认；本次未执行正式语雀全量导出，运行证据来自脱敏样本、公开只读真实画板和隔离 Obsidian 实例。

## 重要更新

### 新增功能

- `src/board.js` 新增统一 BoardIR，保留节点坐标、尺寸、颜色、形状、原始顺序、连线锚点和 `points/path` 路径，并输出结构完整度、布局完整度及流向统计。
- 新增 `src/board-render.js`，按画板类型、复杂度和目标 Vault 能力选择 Markmap、普通 Markdown、Mermaid、Excalidraw 或 PNG 主产物。
- 新增 `src/excalidraw.js`，将布局敏感流程图写成标准 Excalidraw `compressed-json`，节点文字使用原生绑定，箭头保留起点和终点绑定。
- 新增 Excalidraw 增量保护：同源且未变化时幂等跳过；来源变化且产物由程序生成时先写入 `history/` 再更新；检测到人工修改时生成 `.yuque-update.excalidraw.md`，不覆盖原文件。
- 新增 `*.manifest.json` 清单，记录来源哈希、生成哈希、分类、节点/连线数量、输出文件、告警和 PNG 截图状态。
- 独立复杂画板可直接以 `.excalidraw.md` 作为主文件；嵌入式画板在原 Markdown 位置提供“打开可编辑流程图”入口。
- 新增 Obsidian 图形能力检测，只认已启用且实际存在的 Markmap、Excalidraw 和 Excalidraw Extras 插件；Excalidraw 文件生成不再把 CLI Vault 注册作为硬前提。

### 已有功能调整

- 结构化导出成功时，默认 `fallback-only` 策略不再无条件生成 PNG；只有部分结构化、布局敏感回退或结构化失败时才保留截图。
- Mermaid 流程图方向由节点位置推断，支持 `TD/TB/BT/LR/RL`，不再固定为纵向 `TD`。
- Excalidraw 连线取消边缘分散逻辑：同一方向的一对多、多对一连线统一接入对应边中心；混合方向分别使用正确边中心；无原始路径时仅做必要的外部正交避障。
- 有语雀原始 `points/path` 时优先保留中间折点，不再按几何中点重新计算折线。
- Canvas 侧车改为兼容性输出，不再作为新桌面配置下的默认主产物；旧 API 仍可显式请求 Canvas。
- 桌面端新增“图形导出”模式：自动推荐、通用兼容、Obsidian 可编辑增强；CLI 配置和环境变量同步支持图形导出/截图模式。

### 问题修复

- 修复复杂流程图箭头回环、边缘连接点分散、混合方向接错边以及直线穿过中间节点的问题。
- 修复 Excalidraw 文字或箭头绑定丢失风险，新增写入后回读校验，检查元素 ID、节点数量、连线数量和双端绑定。
- 修复 PNG 异步截图完成后 manifest 未同步生成文件和截图状态的问题。
- 修复桌面设置文件带 UTF-8 BOM 时 JSON 解析失败、导致全部设置无法加载的问题。
- 修复结构化输出与正文/独立画板重复生成 Markdown 外壳的问题。

### 文档变更

- 新增《语雀画板图形导出升级实施方案》，明确四类画板分流、BoardIR 边界、文件策略、验收门槛和完成标准。
- 新增《语雀画板图形导出升级操作层面步骤》，固化模块实施顺序、隔离 Obsidian 验收、回滚边界和文档哈希校验方法。
- 新增并更新《语雀画板图形导出升级验证记录》，记录真实画板 46 节点/49 连线、Excalidraw 绑定校验、隔离运行时视觉复核、拖动与重开验证；自动化测试数量修正为 193 项 Node 测试。
- 本版本说明同步保存到项目 `docs/` 和 Obsidian 知识库对应的“语雀批量导出”目录。

### 部署配置相关变更

- `package.json`、`package-lock.json`、`yarn.lock` 新增并锁定 `lz-string@1.5.0`，用于 Excalidraw 压缩 JSON 读写。
- 桌面端默认新增 `diagramExportMode=auto`、`diagramSnapshotMode=fallback-only`，CLI 默认值与桌面端保持一致。
- 目标 Vault 只需启用 Excalidraw 插件即可生成标准可编辑文件；CLI 未注册时仍可生成，自动打开/命令调用能力单独降级。
- `runtime-validation/` 保留为隔离验收证据和运行现场，本次不作为正式版本源码提交。
