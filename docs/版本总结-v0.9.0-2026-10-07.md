# v0.9.0 版本总结：收藏与协作文档导出

- 版本：v0.9.0
- 日期：2026-10-07
- 发布主题：收藏与协作文档导出
- 交付状态：已提交本地并创建本地 tag；未推送远端；未构建本轮 EXE

## 重要变化

### 新增功能

- 新增收藏与协作文档来源扫描；仅导出用户明确勾选的具体文档，不展开知识库入口。
- 新增收藏/协作来源去重、分页扫描进度与取消、来源索引及按文档身份直接重试。
- 新增单篇文档计划、文档级资源目录、Sheet 表格与 Obsidian Bases 数据集输出。
- 新增失败、受限、未完成及本地修改保护等导出结果分类和提示。

### 已有功能调整

- 来源导出状态升级至 v2，兼容旧 URL 状态，并保护已有本地修改与目标目录中的手写文件。
- 桌面默认输出目录改为下载目录，导出布局默认直写 Obsidian 仓库；数据表设置默认采用 Bases 与社区插件选项。
- 收紧桌面设置与内容列表布局，统一下拉框、分类选择、进度显示和任务结果文案。
- Sheet 输出保留合并单元格及可识别的背景色、文字颜色。

### 问题修复

- 修复收藏来源 Sheet 被界面禁选、仅选 Sheet 时导出按钮不可用的问题。
- 修复登录 Cookie 分区兼容、来源任务取消/重试边界、资源目录名校验及若干 Markdown 结构问题。
- 限制外部资源下载不携带语雀凭据、不跟随重定向，并校验资源响应类型。

### 文档变更

- 新增收藏与协作文档导出实施方案及关键测试记录。
- 新增截至 2026-10-06 的开发进度与后续对话交接记录。

## 影响范围

- 现有知识库导出流程保留；新增来源路径只处理显式选择的收藏/协作文档，不递归扫描其所属知识库。
- 默认输出和 Obsidian 写入设置发生变化；已有配置值仍以用户保存的设置为准。
- 真实样本已验证普通 Markdown 与图片的部分链路；空 target 条目、非图片附件、Sheet 内资源/本地修改保护及通用复杂块仍有验收缺口。

## 验证记录

- 定向 Node 测试：146 项通过，覆盖 CLI、来源计划/扫描/导出、状态兼容、资源安全、Markdown、登录及桌面 UI 结构。
- 定向 Python unittest：27 项通过，覆盖桌面设置、来源桥接、重试和更新模块。
- `git diff --check`：通过。
- 用户此前确认 9 篇来源文档可在 Obsidian 查看；这不代表所有内容类型均已验收。
- 未验证：本轮打包后的 EXE、解锁桌面后的完整视觉验收、全部复杂块/附件/Sheet 资源及全量测试套件。
